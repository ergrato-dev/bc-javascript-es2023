## 🧩 El Reto Final

### Contexto

Esta semana integras **TODO lo aprendido** en las semanas 1-11. Es tu proyecto de graduación de los fundamentos.

### Tu Misión

Completa el **E-commerce App** aplicando al menos **10 características ES2019-ES2023**:

| Característica | Semana | Aplicación Sugerida |
|----------------|--------|---------------------|
| Optional chaining `?.` | 01 | Acceso a datos de usuario |
| Nullish coalescing `??` | 01 | Valores por defecto |
| `at(-1)` | 02 | Último producto visto |
| `Object.hasOwn()` | 02 | Verificar propiedades |
| Private fields `#` | 03 | Datos sensibles en clases |
| Static blocks | 03 | Inicialización de servicios |
| Top-level await | 04 | Carga inicial de datos |
| `findLast()` | 05 | Búsqueda en historial |
| `toSorted()` | 05 | Ordenar sin mutar |
| RegExp `/d` flag | 06 | Validación con índices |
| WeakMap + Symbol | 07 | Caché privado |
| Generadores | 08 | Paginación lazy |
| Well-known Symbols | 09 | Objetos iterables |
| Proxy/Reflect | 10 | Validación reactiva |
| Error cause | 11 | Manejo de errores robusto |
| Optional catch | 11 | Fallbacks silenciosos |

### Requisito Mínimo

Tu E-commerce debe usar **al menos 10** de las características anteriores, documentando dónde y por qué las usaste.
