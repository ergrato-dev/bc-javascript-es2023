# 🎬 Videografía - Semana 23

1. [Cápsula JS: Debounce & Throttle](https://www.youtube.com/watch?v=K_WCErEfX-A) - vanessamarely (español). Las dos técnicas aplicadas a `scroll`, `keyup` y `resize`. Repaso de la teoría 02.
2. [Mejora tu app con debounce en JavaScript](https://www.youtube.com/watch?v=W1sOOTjtfh0) - lasfito (español). Un debounce escrito paso a paso para un buscador. Repaso del lab 02.
3. [Cápsula de JavaScript: Intersection Observer](https://www.youtube.com/watch?v=oJund-nB90k) - vanessamarely (español). Detectar qué elementos están a la vista para cargarlos o animarlos. Repaso de la teoría 03.
4. [Lazy-Loaded Images - Code This, Not That](https://www.youtube.com/watch?v=aUjBvuUdkhg) - Fireship (inglés). Cargar imágenes al verlas con `IntersectionObserver` en lugar de escuchar `scroll`. Repaso del lab 03.
5. [Plugging Memory Leaks With The Chrome Dev Tools](https://www.youtube.com/watch?v=Hr2vrhrNaRo) - Ben Dilts en UtahJS (inglés). Una charla sobre cómo encontrar fugas con las fotos de memoria de las DevTools. La interfaz ha cambiado algo desde entonces; los pasos actuales están en la [teoría 04](../../1-teoria/04-fugas-memoria.md#8-encontrar-fugas).
