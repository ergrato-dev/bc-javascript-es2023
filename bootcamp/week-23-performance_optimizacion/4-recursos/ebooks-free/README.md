# 📘 eBooks gratuitos - Semana 23

1. [Decoradores y redirecciones, call/apply](https://es.javascript.info/call-apply-decorators) - *El Tutorial de JavaScript Moderno* (español). Una caché que envuelve una función (memoize) y, en sus ejercicios, debounce y throttle. Repaso de las teorías 02 y 03.
2. [Recolección de basura](https://es.javascript.info/garbage-collection) - *El Tutorial de JavaScript Moderno* (español). Raíces, objetos alcanzables y cómo trabaja el recolector. Repaso de la teoría 04.
3. [WeakMap y WeakSet](https://es.javascript.info/weakmap-weakset) - *El Tutorial de JavaScript Moderno* (español). Claves débiles y sus usos: datos asociados y cachés. Repaso de la teoría 04.
4. [WeakRef and FinalizationRegistry](https://javascript.info/weakref-finalizationregistry) - *The Modern JavaScript Tutorial* (inglés). Las referencias débiles y el aviso de borrado que usa el lab 04. Lectura opcional.
5. [Handling Events](https://eloquentjavascript.net/15_event.html) - *Eloquent JavaScript*, 4.ª edición, de Marijn Haverbeke (inglés). El apartado «Debouncing» resuelve el mismo problema con `setTimeout`. Lectura opcional.
