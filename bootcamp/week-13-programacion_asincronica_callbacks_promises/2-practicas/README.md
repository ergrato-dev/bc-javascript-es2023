# Prácticas — Semana 13

Cuatro labs guiados. Cada lab trae en `starter/` el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. Antes de ejecutar, intenta predecir el orden de las líneas: en código asíncrono, ese orden es lo que se aprende. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-callbacks/README.md) | Callbacks síncronos y asíncronos, event loop, *callback hell* y *error-first* | 50 min |
| [Lab 02](lab-02-promises-basicas/README.md) | `new Promise`, estados, `then`/`catch`/`finally` y de callback a promesa | 50 min |
| [Lab 03](lab-03-promise-chaining/README.md) | Encadenar `.then()`, propagar errores y recuperarse de ellos | 55 min |
| [Lab 04](lab-04-promise-combinators/README.md) | `Promise.all()`, `race()`, `allSettled()` y `any()` | 55 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
