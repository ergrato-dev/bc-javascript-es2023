# 🌐 Webgrafía - Semana 13

## Documentación

1. [MDN - Promise](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Promise): referencia de la clase y de sus métodos estáticos (`all`, `allSettled`, `any`, `race`, `resolve`, `reject`, `withResolvers`).
2. [MDN - Usar promesas](https://developer.mozilla.org/es/docs/Web/JavaScript/Guide/Using_promises): guía de encadenamiento, errores y composición.
3. [MDN - El bucle de eventos](https://developer.mozilla.org/es/docs/Web/JavaScript/Event_loop): modelo de concurrencia de JavaScript.
4. [JavaScript.info - Promises, async/await](https://es.javascript.info/async): capítulos sobre callbacks, promesas, encadenamiento y la API de `Promise`, con ejercicios.

## Artículos

5. [web.dev - JavaScript Promises: an introduction](https://web.dev/articles/promises): explicación detallada con ejemplos (inglés).
6. [V8 - Promise combinators](https://v8.dev/features/promise-combinators): por qué existen `allSettled` y `any`, y cuándo usar cada combinador (inglés).
7. [Node.js - The Node.js Event Loop](https://nodejs.org/en/learn/asynchronous-work/event-loop-timers-and-nexttick): fases del bucle de eventos en Node, temporizadores y microtareas (inglés).

## Herramientas

8. [Loupe](http://latentflip.com/loupe/): visualiza paso a paso la pila, las APIs y la cola de callbacks de un fragmento de código.
9. [Promisees](https://bevacqua.github.io/promisees/): dibuja cómo se resuelve cada promesa de una cadena.
