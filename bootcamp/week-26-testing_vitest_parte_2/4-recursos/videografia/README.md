# 🎬 Videografía - Semana 26

1. [Ejemplo de VITEST MOCK FETCH (TypeScript) FÁCIL y RÁPIDO](https://www.youtube.com/watch?v=na_cUiY9O8c) - Developero (español). Un test con un `fetch` falso en Vitest. Está escrito en TypeScript: quita los tipos y el código es el mismo JavaScript del bootcamp. Repaso del lab 01 y de la teoría 01.
2. [Curso de Test Driven Development desde Cero con JavaScript, React y Vitest](https://www.youtube.com/watch?v=_t9l2TwGioc) - midulive (español). TDD paso a paso: rojo, verde y refactorizar con katas. La primera parte, sin React, es la del lab 04.
3. [Day 4 - Time Travel with Fake Timers](https://www.youtube.com/watch?v=aneQh5DgboE) - Marc Littlemore (inglés). El reloj falso explicado desde cero. Si el código usa `jest.` delante, en Vitest es `vi.`: `vi.useFakeTimers`, `vi.advanceTimersByTime`. Repaso de la teoría 02.
4. [Vitest for React with Vite: Unit & Integration Testing with API Mocking](https://www.youtube.com/watch?v=AoQ8jzDV5oI) - QA Routine (inglés). Tests unitarios y de integración de una app que pide datos a una API. Usa React, pero la separación entre los dos tipos de test es la de la teoría 03. Opcional.
