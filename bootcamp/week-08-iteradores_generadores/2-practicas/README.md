# Prácticas — Semana 08

Cuatro labs guiados que siguen el orden de la teoría. Cada lab trae en `starter/index.js` el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-iterators/README.md) | Protocolo de iteración: `Symbol.iterator`, `next()` e iterables propios | 50 min |
| [Lab 02](lab-02-for-loops/README.md) | `for...of` frente a `for...in`, y `Object.entries()`, `keys()` y `values()` | 45 min |
| [Lab 03](lab-03-generators/README.md) | `function*`, `yield`, `yield*`, secuencias infinitas y `next(value)` | 60 min |
| [Lab 04](lab-04-custom-iterable/README.md) | Clases iterables con `*[Symbol.iterator]()` | 55 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
