# 🎬 Videografía - Semana 20

1. [Using FormData Objects Effectively](https://www.youtube.com/watch?v=GWJhE7Licjs) - Steve Griffith (inglés). Crear un `FormData` a partir de un formulario, leerlo y enviarlo. Repaso del lab 01.
2. [Supercharge your forms with the Constraint Validation API](https://www.youtube.com/watch?v=2iXLIlfpcVA) - Chrome for Developers (inglés). Atributos de validación, `validity` y mensajes propios en formularios accesibles. Repaso de las teorías 02 y 03.
3. [Método setCustomValidity de Javascript](https://www.youtube.com/watch?v=lzlUzo8ITQY) - Diana Giraldo (español). Reglas propias con `setCustomValidity()`. Repaso del lab 03, paso 4.
4. [How to Create a Custom Form Validator with JavaScript](https://www.youtube.com/watch?v=fE5ASN0sbtI) - dcode (inglés). Un validador propio con reglas y mensajes por campo. Repaso de la teoría 04.
