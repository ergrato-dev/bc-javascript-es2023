# 📖 Ebooks gratuitos - Semana 20

1. **JavaScript.info - Formularios y controles** - Ilya Kantor
   - Enlace: [es.javascript.info/form-elements](https://es.javascript.info/form-elements)
   - `form.elements`, `value`, `checked` y `<select>`, con ejercicios. Sigue con [el evento submit](https://es.javascript.info/forms-submit) y con [FormData](https://es.javascript.info/formdata), que lo envía con `fetch`
   - Nivel: principiante · Idioma: español

2. **Eloquent JavaScript - Capítulo 18: HTTP and Forms** - Marijn Haverbeke
   - Enlace: [eloquentjavascript.net/18_http.html](https://eloquentjavascript.net/18_http.html)
   - Cómo viajan los datos de un formulario por HTTP, los campos, el foco y el evento `submit`
   - Nivel: intermedio · Idioma: inglés

3. **MDN Learn - Client-side form validation** - MDN
   - Enlace: [developer.mozilla.org](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation)
   - Tutorial guiado: atributos de validación, la API de validación y validación propia con JavaScript. Sigue con [Sending forms through JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Sending_forms_through_JavaScript)
   - Nivel: principiante · Idioma: inglés
