# 🌐 Webgrafía - Semana 20

## Documentación

1. [MDN - FormData](https://developer.mozilla.org/es/docs/Web/API/FormData): el constructor y los métodos `get`, `getAll`, `has`, `append` y `set`.
2. [MDN - HTMLFormElement.requestSubmit()](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/requestSubmit): enviar desde código como si se pulsara un botón, y en qué se diferencia de `submit()` (inglés).
3. [MDN - Constraint validation](https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Constraint_validation): qué restricciones hay, cuándo se comprueban y cómo se leen desde JavaScript (inglés).
4. [MDN - ValidityState](https://developer.mozilla.org/en-US/docs/Web/API/ValidityState): cada indicador de `validity` y qué lo activa (inglés).
5. [MDN - setCustomValidity()](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/setCustomValidity): reglas propias y por qué hay que volver a `''` (inglés).
6. [MDN - :user-invalid](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:user-invalid): la pseudoclase que marca un campo solo después de que la persona lo toque (inglés).

## Guías y artículos

7. [web.dev - Help users enter the right data in forms](https://web.dev/learn/forms/validation): validación con HTML, CSS y JavaScript, y cuándo mostrar los errores (inglés).
8. [web.dev - Accessibility](https://web.dev/learn/forms/accessibility): etiquetas, mensajes de error enlazados con `aria-describedby` y formularios que se usan con teclado (inglés).
