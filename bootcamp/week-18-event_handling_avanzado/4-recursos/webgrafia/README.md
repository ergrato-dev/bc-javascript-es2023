# 🌐 Webgrafía - Semana 18

## Documentación

1. [MDN - addEventListener](https://developer.mozilla.org/es/docs/Web/API/EventTarget/addEventListener): todas las opciones (`once`, `passive`, `signal`, `capture`) y el valor de `this` dentro del listener.
2. [MDN - KeyboardEvent.key](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key): los valores de `key` y la diferencia con `code` (inglés).
3. [MDN - preventDefault](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault): qué cancela, qué no y los eventos que no se pueden cancelar (inglés).
4. [MDN - Creating and triggering events](https://developer.mozilla.org/en-US/docs/Web/Events/Creating_and_triggering_events): `Event`, `CustomEvent` y `dispatchEvent`, con ejemplos de eventos que suben (inglés).
5. [MDN - CustomEvent()](https://developer.mozilla.org/en-US/docs/Web/API/CustomEvent/CustomEvent): el constructor y sus opciones `detail`, `bubbles` y `cancelable` (inglés).
6. [Node.js - EventTarget and Event API](https://nodejs.org/api/events.html): el `EventTarget` de Node que usan las comprobaciones del proyecto (inglés).

## Guías y artículos

7. [Chrome for Developers - Use passive listeners to improve scrolling performance](https://developer.chrome.com/docs/lighthouse/best-practices/uses-passive-event-listeners): por qué un listener de `wheel` o `touchmove` sin `passive` puede frenar el desplazamiento (inglés).
