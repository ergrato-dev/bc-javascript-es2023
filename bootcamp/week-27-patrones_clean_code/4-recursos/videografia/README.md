# 🎬 Videografía - Semana 27

1. [PATRONES DE DISEÑO explicados en 10 minutos](https://www.youtube.com/watch?v=UxpbLfynMng) - otro más de sistemas (español). Qué es un patrón de diseño y los tipos que hay, con ejemplos en JavaScript. La introducción de la teoría 01, para empezar.
2. [Patrón observador en Javascript](https://www.youtube.com/watch?v=pReYTx2frTQ) - hdeleon.net (español). El patrón Observer escrito desde cero en JavaScript. Usa clases donde el lab 02 usa una fábrica: compara las dos versiones.
3. [OBSERVER (El PATRÓN que lo ve TODO)](https://www.youtube.com/watch?v=HFkZb1g8faA) - BettaTech (español). Por qué existe el Observer y qué problema resuelve, con ejemplos. Repaso de la teoría 02.
4. [FACTORY: PATRÓN de DISEÑO con VARIOS EJEMPLOS](https://www.youtube.com/watch?v=Xjwlmpkkp6M) - Terminal Life (español). El patrón Factory en TypeScript y JavaScript. Quita los tipos y es la fábrica que elige qué crear de la teoría 01.
5. [JavaScript Clean Code Course – Fix Code Smells & Refactor](https://www.youtube.com/watch?v=626BcUO84og) - freeCodeCamp.org (inglés). Un curso de olores del código y refactor en JavaScript. Repaso de las teorías 03 y 05; elige las partes de los olores que te costaron en el proyecto.
6. [How to Set Up ESLint 9 with Prettier in Node.js (Flat Config + VS Code Auto-Format)](https://www.youtube.com/watch?v=IcCHLLEtiHM) - Leela Web Dev (inglés). ESLint con configuración plana, Prettier y el formato al guardar en VS Code. Usa ESLint 9 y npm: en el bootcamp, ESLint 10 y `pnpm add --save-dev`; la configuración es la misma. Opcional, para la pregunta 4 del lab 04.
