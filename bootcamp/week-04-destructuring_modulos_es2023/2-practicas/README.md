# Prácticas — Semana 04

Cuatro labs guiados que siguen el orden de la teoría. Cada lab trae en `starter/` el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. Los labs 03 y 04 reparten el código en varios archivos, como un proyecto real. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-destructuring-arrays/README.md) | Destructuring de arrays | 45 min |
| [Lab 02](lab-02-destructuring-objetos/README.md) | Destructuring de objetos | 55 min |
| [Lab 03](lab-03-modulos-basicos/README.md) | `export`, `import`, barrel y `export default` | 55 min |
| [Lab 04](lab-04-imports-avanzados/README.md) | `import()` dinámico, `Promise.all` y caché de módulos | 55 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
