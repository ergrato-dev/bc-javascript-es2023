# Prácticas — Semana 05

Cinco labs guiados que siguen el orden de la teoría. Cada lab trae en `starter/index.js` el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-flat-flatmap/README.md) | `flat()` y `flatMap()` | 40 min |
| [Lab 02](lab-02-array-from-of/README.md) | `Array.from()` y `Array.of()` | 40 min |
| [Lab 03](lab-03-chaining/README.md) | Encadenar métodos | 45 min |
| [Lab 04](lab-04-sort-transform/README.md) | Ordenar, agrupar e indexar | 45 min |
| [Lab 05](lab-05-findlast/README.md) | `findLast()`, `findLastIndex()`, `with()` y `toSpliced()` | 40 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
