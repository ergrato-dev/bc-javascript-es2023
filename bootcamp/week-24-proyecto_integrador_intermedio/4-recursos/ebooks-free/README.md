# 📘 eBooks gratuitos - Semana 24

1. [Fetch: Abort](https://es.javascript.info/fetch-abort) - *El Tutorial de JavaScript Moderno* (español). `AbortController` con `fetch` y cancelar varias peticiones a la vez. Repaso del lab 01.
2. [Promise API](https://es.javascript.info/promise-api) - *El Tutorial de JavaScript Moderno* (español). `Promise.all`, `allSettled`, `race` y `any`. Repaso del lab 01, paso 5.
3. [LocalStorage, sessionStorage](https://es.javascript.info/localstorage) - *El Tutorial de JavaScript Moderno* (español). Los métodos, el límite de tamaño y el evento `storage`. Repaso del lab 02.
4. [Delegación de eventos](https://es.javascript.info/event-delegation) - *El Tutorial de JavaScript Moderno* (español). Un listener para muchos elementos, con `closest` y atributos `data-*`. Repaso del lab 03.
5. [HTTP and Forms](https://eloquentjavascript.net/18_http.html) - *Eloquent JavaScript*, 4.ª edición, de Marijn Haverbeke (inglés). HTTP, `fetch` y formularios en un solo capítulo: el repaso de media etapa. Lectura opcional.
