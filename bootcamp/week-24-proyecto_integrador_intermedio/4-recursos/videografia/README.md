# 🎬 Videografía - Semana 24

1. [CRUD con LocalStorage y Vanilla Javascript](https://www.youtube.com/watch?v=zeb5PsxWijY) - Bluuweb (español). Una aplicación pequeña que crea, lista y borra datos guardados en `localStorage`, sin librerías. Compárala con el proyecto: allí los datos viven en una API y `localStorage` solo guarda una copia.
2. [Curso Javascript - LocalStorage & SessionStorage](https://www.youtube.com/watch?v=XpkchCqNKQ4) - Programando el Destino (español). Las dos APIs de almacenamiento y sus diferencias. Repaso del lab 02.
3. [Javascript #09: DOM delegación de eventos](https://www.youtube.com/watch?v=OspjzGQa86g) - Bluuweb (español). Un listener en el contenedor en lugar de uno por elemento. Repaso del lab 03, paso 4.
4. [CONSEJO: Estas usando mal los Event Listeners en Javascript](https://www.youtube.com/watch?v=GUTt0qKUDyU) - FalconMasters (español). Por qué la delegación funciona con elementos que se crean después. Repaso del lab 03.
5. [Abort API Requests in JavaScript using the AbortController](https://www.youtube.com/watch?v=EvAuLZUOG2Q) - Deeecode (inglés). Cancelar peticiones con `AbortController`. Repaso del lab 01, paso 3.
