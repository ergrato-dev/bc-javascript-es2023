# Prácticas — Semana 01

Cinco labs guiados, uno por cada tema de la teoría. Cada lab trae un `starter/index.js` con el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-variables-const-let/README.md) | Variables con `const` y `let` | 40 min |
| [Lab 02](lab-02-template-literals/README.md) | Template literals | 40 min |
| [Lab 03](lab-03-arrow-functions/README.md) | Arrow functions | 45 min |
| [Lab 04](lab-04-destructuring/README.md) | Destructuring | 45 min |
| [Lab 05](lab-05-operadores-modernos/README.md) | Operadores modernos | 40 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
