# 📖 eBooks Gratuitos - Semana 06

## Strings y RegExp Modernos

### 📚 Libros Recomendados

#### JavaScript General (con secciones de Strings/RegExp)

1. **Eloquent JavaScript** - Marijn Haverbeke
   - 🔗 [eloquentjavascript.net](https://eloquentjavascript.net/)
   - 📖 Capítulo 9: Regular Expressions
   - 💡 Explicaciones claras con ejemplos prácticos
   - 🌐 Disponible en español

2. **JavaScript.info - The Modern JavaScript Tutorial**
   - 🔗 [javascript.info](https://javascript.info/)
   - 📖 Sección: Strings, Regular Expressions
   - 💡 Tutorial interactivo con ejercicios
   - 🌐 Disponible en español

3. **You Don't Know JS Yet** - Kyle Simpson
   - 🔗 [github.com/getify/You-Dont-Know-JS](https://github.com/getify/You-Dont-Know-JS)
   - 📖 Serie completa sobre JavaScript profundo
   - 💡 Entender el "por qué" detrás de JS

#### RegExp Específicos

4. **Regular Expressions - The Complete Tutorial**
   - 🔗 [regular-expressions.info](https://www.regular-expressions.info/)
   - 📖 Tutorial completo de RegExp
   - 💡 Cubre todos los sabores de regex

5. **Learn Regex the Easy Way**
   - 🔗 [github.com/ziishaned/learn-regex](https://github.com/ziishaned/learn-regex)
   - 📖 Guía visual y práctica
   - 💡 Ejemplos claros y concisos
   - 🌐 Múltiples idiomas
