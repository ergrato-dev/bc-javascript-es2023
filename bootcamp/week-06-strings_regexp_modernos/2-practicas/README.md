# Prácticas — Semana 06

Cuatro labs guiados que siguen el orden de la teoría. Cada lab trae en `starter/index.js` el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-string-methods/README.md) | Métodos modernos de strings | 50 min |
| [Lab 02](lab-02-template-tags/README.md) | Tagged templates y `String.raw` | 50 min |
| [Lab 03](lab-03-regexp-basics/README.md) | Fundamentos de RegExp | 55 min |
| [Lab 04](lab-04-matchall-search/README.md) | `matchAll()`, grupos con nombre y flag `d` | 55 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
