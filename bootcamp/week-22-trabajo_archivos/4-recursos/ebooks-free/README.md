# 📘 eBooks gratuitos - Semana 22

1. [Blob](https://es.javascript.info/blob) - *El Tutorial de JavaScript Moderno* (español). Crear un `Blob`, URLs de objeto, base64 y descargas con `<a download>`. Repaso de las teorías 01 y 03.
2. [File y FileReader](https://es.javascript.info/file) - *El Tutorial de JavaScript Moderno* (español). `File`, `<input type="file">` y los métodos y eventos de `FileReader`. Repaso de la teoría 02.
3. [HTTP and Forms](https://eloquentjavascript.net/18_http.html) - *Eloquent JavaScript*, 4.ª edición, de Marijn Haverbeke (inglés). El apartado «File fields» lee archivos elegidos con `FileReader` dentro del contexto de los formularios. Lectura opcional.
