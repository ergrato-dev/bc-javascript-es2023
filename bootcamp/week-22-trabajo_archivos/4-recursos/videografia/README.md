# 🎬 Videografía - Semana 22

1. [Uploader de archivos con drag & drop](https://www.youtube.com/watch?v=GtRK8VGAy6w) - jonmircha (español). Una zona de arrastrar y soltar con los eventos `dragover` y `drop`. Repaso de la teoría 04; la parte de enviar los archivos a un servidor con PHP no entra esta semana.
2. [Cómo subir varios archivos con JavaScript arrastrándolos al navegador](https://www.youtube.com/watch?v=4NTiCGxHsW0) - PadawansTrainer (español). Un input `multiple` y una zona de soltar que comparten el mismo código. Repaso del lab 04; el envío con `fetch` es de la [semana 15](../../../week-15-fetch_api/README.md).
3. [JavaScript FileReader](https://www.youtube.com/watch?v=-AR-6X_98rM) - Kyle Robinson Young (inglés). Leer archivos de un input y de un arrastre con `FileReader`. Repaso del lab 02.
4. [How to Drag and Drop Files with Javascript](https://www.youtube.com/watch?v=9Xh_ZpFkROI) - Dave Gray (inglés). Una zona de soltar paso a paso, con el input como alternativa. Repaso de la teoría 04.
5. [Downloading Text Using Blobs, URL.createObjectURL(), And The Anchor Download Attribute In JavaScript](https://www.youtube.com/watch?v=aCwmSI-z2kQ) - Ben Nadel (inglés). Descargar un texto creado en la página con un `Blob`, una URL de objeto y `<a download>`. Repaso del lab 03.
