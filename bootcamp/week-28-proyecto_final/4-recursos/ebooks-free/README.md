# 📚 Ebooks gratuitos - Semana 28

1. [JavaScript & Node.js Testing Best Practices](https://github.com/goldbergyoni/javascript-testing-best-practices/blob/master/readme-es.md) - Yoni Goldberg (traducción al español). Más de 50 consejos para escribir tests, cada uno con un ejemplo «mal» y otro «bien»: títulos que dicen qué se prueba, preparar-actuar-comprobar, datos realistas, qué no garantiza la cobertura. Los ejemplos usan Jest o Mocha; con Vitest, `describe`, `it` y `expect` funcionan igual. Lee la sección 1, «La Anatomía de un Test», antes de escribir los tests del proyecto.
2. [Eloquent JavaScript, capítulo 21: Project: Skill-Sharing Website](https://eloquentjavascript.net/21_skillsharing.html) - Marijn Haverbeke (inglés). El último capítulo del libro es, como esta semana, una aplicación completa: un servidor con Node, una API y una página que guarda su estado en un objeto y lo cambia con acciones. Compara su `handleAction` con tu `reduce`, y su forma de repartir el código con la tuya.
