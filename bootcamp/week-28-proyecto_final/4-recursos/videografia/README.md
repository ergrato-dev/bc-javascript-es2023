# 🎬 Videografía - Semana 28

1. [Redux desde cero - ¡Primeros pasos e introducción a Redux en español!](https://www.youtube.com/watch?v=QEsukdXFxxs) - midudev (español). Store, acciones, reductor, `dispatch` y `subscribe` con Redux, la librería que popularizó el almacén de tu proyecto. Las ideas son las mismas que tu `createStore`; fíjate en lo que Redux añade y en lo que no necesitas.
2. [Episodio #25: Testing desde cero: Unit, integration, e2e, mocks, spies, stubs, TDD, BDD y más](https://www.youtube.com/watch?v=R6aIVimcma8) - Xabadu (español). Un repaso de los tipos de tests y de los dobles de prueba de las semanas 25 y 26. Útil para responder en la presentación qué prueba cada test del proyecto.
3. [Ejemplo de VITEST MOCK FETCH (TypeScript) FÁCIL y RÁPIDO](https://www.youtube.com/watch?v=na_cUiY9O8c) - Developero (español). Cómo sustituir `fetch` en un test de Vitest. Usa TypeScript y cambia el `fetch` global; en el proyecto, `createApi` lo recibe como parámetro y no hace falta tocar el global. Compara las dos formas.
4. [Manage State in JavaScript Like a Pro!](https://www.youtube.com/watch?v=7i1f4PKSlxo) - Syntax (inglés). Estado en JavaScript sin frameworks: un único objeto, funciones que lo cambian y quién se entera. Opcional, para comparar con la arquitectura de la teoría 02.
