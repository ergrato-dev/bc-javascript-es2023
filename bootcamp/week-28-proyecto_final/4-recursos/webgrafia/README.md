# 🌐 Webgrafía - Semana 28

## Arquitectura y estado

1. [Redux Fundamentals, Part 2: Concepts and Data Flow](https://redux.js.org/tutorials/fundamentals/part-2-concepts-data-flow) - Redux (inglés). El flujo en una sola dirección (acción, reductor, estado, vista), con diagramas animados. Es el camino de una acción de la teoría 02.
2. [Patrón Observer](https://www.patterns.dev/vanilla/observer-pattern) - Patterns.dev (inglés). El patrón de `subscribe`, con sus ventajas y sus problemas.

## Tests

3. [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) - Ham Vocke en el sitio de Martin Fowler (inglés). Cuántos tests unitarios, de integración y de punta a punta escribir, y qué prueba cada uno. Los ejemplos son de Java; las ideas valen igual.
4. [Mocking](https://vitest.dev/guide/mocking) - Vitest (inglés). `vi.fn`, `vi.spyOn` y `vi.mock`, con las formas de sustituir `fetch` y las peticiones.
5. [Coverage](https://vitest.dev/guide/coverage) - Vitest (inglés). `include`, `thresholds` y los informes de cobertura de `vitest.config.js`.
6. [Response](https://developer.mozilla.org/es/docs/Web/API/Response) - MDN. El objeto que devuelve `fetch` y que construyen tus `fetch` falsos: `status`, [`ok`](https://developer.mozilla.org/es/docs/Web/API/Response/ok) y `json()`.
