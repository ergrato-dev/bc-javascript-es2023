# Prácticas — Semana 28

Dos labs guiados con Node que juntan piezas que ya conoces, en la forma en que las usa el proyecto final. El lab 01 no instala nada: descomentas un bloque de `index.js`, lo ejecutas con `node index.js` y comparas la salida. El lab 02 tiene su `package.json` y su `pnpm-lock.yaml`: descomentas tests y arreglas lo que encuentran la cobertura, ESLint y Prettier. No se entregan; preparan el [proyecto final](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-almacen-y-vista/README.md) | Un reductor con Strategy, un almacén con Observer, tres fallos silenciosos de un almacén escrito deprisa y una vista que se calcula desde el estado | 1 h |
| [Lab 02](lab-02-cadena-de-calidad/README.md) | Un cliente de API con `fetch` inyectado: tests con un `fetch` falso y contra un servidor, cobertura mínima, ESLint, Prettier y `pnpm check` | 1 h |

**Total:** 2 h.

## Antes de empezar

Necesitas Node y pnpm en las versiones de [docs/stack-versions.md](../../../docs/stack-versions.md). El lab 02 instala Vitest 5.1.0, `@vitest/coverage-v8` 5.1.0, ESLint 10.14.0 y Prettier 3.10.0, las mismas versiones que el proyecto.

Los labs muestran salidas reales. En el lab 02 cambian `Start at`, `Duration` y los milisegundos de Prettier. Todo lo demás debería coincidir.
