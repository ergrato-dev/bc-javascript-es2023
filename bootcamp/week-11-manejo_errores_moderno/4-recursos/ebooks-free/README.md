## 📚 Libros Recomendados

### 1. You Don't Know JS (YDKJS) - Async & Performance
- **Autor**: Kyle Simpson
- **Enlace**: [GitHub - YDKJS](https://github.com/getify/You-Dont-Know-JS/tree/2nd-ed/sync-async)
- **Relevancia**: Capítulos sobre manejo de errores en código asíncrono
- **Nivel**: Intermedio-Avanzado

### 2. JavaScript: The Good Parts (Excerpts)
- **Autor**: Douglas Crockford
- **Disponible**: Archive.org / Open Library
- **Relevancia**: Patrones defensivos y manejo de excepciones
- **Nivel**: Intermedio

### 3. Eloquent JavaScript (3rd Edition)
- **Autor**: Marijn Haverbeke
- **Enlace**: [eloquentjavascript.net](https://eloquentjavascript.net/)
- **Capítulo relevante**: Chapter 8 - Bugs and Errors
- **Nivel**: Principiante-Intermedio

### 4. JavaScript Allongé
- **Autor**: Reginald Braithwaite
- **Enlace**: [Leanpub (gratis)](https://leanpub.com/javascriptallongesix/read)
- **Relevancia**: Programación funcional y manejo de errores
- **Nivel**: Avanzado

### 5. The Modern JavaScript Tutorial (PDF)
- **Fuente**: javascript.info
- **Enlace**: [javascript.info](https://javascript.info/)
- **Sección**: Error handling
- **Nivel**: Todos los niveles
