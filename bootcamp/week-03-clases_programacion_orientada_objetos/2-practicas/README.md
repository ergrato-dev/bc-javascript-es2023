# Prácticas — Semana 03

Cinco labs guiados que siguen el orden de la teoría. Cada lab trae un `starter/index.js` con el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-clases-basicas/README.md) | Clases, constructor, métodos y composición | 45 min |
| [Lab 02](lab-02-metodos-estaticos/README.md) | Métodos y propiedades estáticas | 40 min |
| [Lab 03](lab-03-herencia/README.md) | `extends`, `super` y polimorfismo | 45 min |
| [Lab 04](lab-04-encapsulacion/README.md) | Campos privados, getters y setters | 45 min |
| [Lab 05](lab-05-static-blocks/README.md) | Static blocks | 35 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
