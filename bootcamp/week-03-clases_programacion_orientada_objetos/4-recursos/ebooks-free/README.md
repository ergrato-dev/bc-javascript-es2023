# 📖 Ebooks Gratuitos - Semana 03

## Clases y POO en JavaScript

### 1. Eloquent JavaScript (Capítulo 6)
- **Autor**: Marijn Haverbeke
- **Enlace**: https://eloquentjavascript.net/06_object.html
- **Idioma**: Inglés (traducción español disponible)
- **Descripción**: Excelente capítulo sobre objetos y clases en JavaScript moderno

### 2. JavaScript.info - Classes
- **Autor**: Ilya Kantor
- **Enlace**: https://javascript.info/classes
- **Idioma**: Inglés/Español
- **Descripción**: Tutorial completo y moderno sobre clases ES2023

### 3. You Don't Know JS: this & Object Prototypes
- **Autor**: Kyle Simpson
- **Enlace**: https://github.com/getify/You-Dont-Know-JS/tree/2nd-ed/objects-classes
- **Idioma**: Inglés
- **Descripción**: Profundiza en prototipos y el sistema de objetos

### 4. The Modern JavaScript Tutorial
- **Enlace**: https://javascript.info/
- **Secciones relevantes**:
  - Classes
  - Prototypes, inheritance
  - Class checking: "instanceof"

## 📥 Cómo Acceder

Todos los recursos listados son **gratuitos** y accesibles online. Algunos ofrecen versión descargable en PDF.

## 🎯 Orden de Lectura Sugerido

1. JavaScript.info - Class basic syntax
2. Eloquent JavaScript - Chapter 6
3. JavaScript.info - Class inheritance
4. You Don't Know JS - Para profundizar
