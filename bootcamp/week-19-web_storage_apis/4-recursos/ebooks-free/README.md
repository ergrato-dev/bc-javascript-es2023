# 📖 Ebooks gratuitos - Semana 19

1. **JavaScript.info - LocalStorage, sessionStorage** - Ilya Kantor
   - Enlace: [es.javascript.info/localstorage](https://es.javascript.info/localstorage)
   - Los métodos, el evento `storage` y las diferencias entre los dos almacenes, con ejercicios. Sigue con [IndexedDB](https://es.javascript.info/indexeddb), que explica versiones, transacciones, índices y cursores, y con [métodos JSON](https://es.javascript.info/json), que trata `toJSON`, el *replacer* y el *reviver*
   - Nivel: principiante a intermedio · Idioma: español

2. **Eloquent JavaScript - Capítulo 18: HTTP and Forms** - Marijn Haverbeke
   - Enlace: [eloquentjavascript.net/18_http.html](https://eloquentjavascript.net/18_http.html)
   - Su última sección, «Storing data client-side», construye una libreta que guarda en `localStorage`
   - Nivel: intermedio · Idioma: inglés

3. **MDN Learn - Client-side storage** - MDN
   - Enlace: [developer.mozilla.org](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Client-side_APIs/Client-side_storage)
   - Tutorial guiado del curso de desarrollo web de MDN: Web Storage con un ejemplo que recuerda un nombre, e IndexedDB con una aplicación de notas
   - Nivel: principiante · Idioma: inglés
