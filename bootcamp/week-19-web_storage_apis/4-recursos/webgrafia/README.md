# 🌐 Webgrafía - Semana 19

## Documentación

1. [MDN - API de almacenamiento web](https://developer.mozilla.org/es/docs/Web/API/Web_Storage_API): conceptos de `localStorage` y `sessionStorage` y cómo se usan.
2. [MDN - Window.localStorage](https://developer.mozilla.org/es/docs/Web/API/Window/localStorage): el objeto, sus métodos y lo que pasa con las páginas `file://`.
3. [MDN - StorageEvent](https://developer.mozilla.org/en-US/docs/Web/API/StorageEvent): las propiedades `key`, `oldValue`, `newValue` y `storageArea` del evento `storage` (inglés).
4. [MDN - JSON.parse()](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/JSON/parse): el *reviver* y los errores que lanza.
5. [MDN - Using IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB): la guía completa de IndexedDB, con versiones, transacciones, índices y cursores (inglés).
6. [MDN - Storage quotas and eviction criteria](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria): cuánto deja guardar cada navegador y cuándo borra datos (inglés).

## Guías y artículos

7. [web.dev - Storage for the web](https://web.dev/articles/storage-for-the-web): qué almacén usar para cada cosa, `navigator.storage.estimate()` y `persist()` (inglés).
