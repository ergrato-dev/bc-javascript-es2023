# 🌐 Webgrafía - Semana 21

## Documentación

1. [MDN - Date](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Date): el constructor, el timestamp, los formatos de texto que acepta y todos sus métodos.
2. [MDN - Date.prototype.toISOString()](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Date/toISOString): el formato ISO 8601 en UTC y el `RangeError` de una fecha inválida.
3. [MDN - Intl.DateTimeFormat](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat): todas las opciones, de `dateStyle` a `timeZone`.
4. [MDN - formatToParts()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/formatToParts): los `type` de cada pieza (inglés).
5. [MDN - Intl.RelativeTimeFormat](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Global_Objects/Intl/RelativeTimeFormat): unidades, `numeric: 'auto'` y estilos.
6. [MDN - Temporal](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal): los tipos de `Temporal` y la tabla de compatibilidad de los navegadores (inglés).
7. [MDN - El elemento time](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/time): el atributo `datetime` que usa el proyecto (inglés).

## Guías y referencias

8. [Documentación de Temporal (TC39)](https://tc39.es/proposal-temporal/docs/): guía y recetario de la API, con ejemplos de cada tipo (inglés).
9. [IANA - Time Zone Database](https://www.iana.org/time-zones): la base de datos de zonas horarias que usan los navegadores y Node (inglés).
10. [Wikipedia - List of tz database time zones](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones): todos los nombres de zona con su desfase y su horario de verano (inglés).
