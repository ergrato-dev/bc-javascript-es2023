# 📘 eBooks gratuitos - Semana 21

1. [El Tutorial de JavaScript Moderno - Fecha y hora](https://es.javascript.info/date) - Ilya Kantor y colaboradores (español). Crear un `Date`, sus componentes, el desbordamiento («autocorrección») y las diferencias entre fechas. Repaso de las teorías 01 y 03.
2. [Eloquent JavaScript - Regular Expressions](https://eloquentjavascript.net/09_regexp.html) - Marijn Haverbeke (inglés). El apartado «The Date class» crea fechas, lee sus componentes y extrae una fecha de un texto con una expresión regular, como `parseLocal` del proyecto.
