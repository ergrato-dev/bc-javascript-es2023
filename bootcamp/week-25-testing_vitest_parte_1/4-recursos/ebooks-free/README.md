# 📘 eBooks gratuitos - Semana 25

1. [Automatización de pruebas con Mocha](https://es.javascript.info/testing-mocha) - *El Tutorial de JavaScript Moderno* (español). Por qué escribir tests, `describe`, `it` y `assert`, y cómo crecer una función test a test. Usa Mocha en lugar de Vitest, pero la forma es la misma. Repaso de las teorías 01 y 02.
2. [JavaScript Testing Best Practices](https://github.com/goldbergyoni/javascript-testing-best-practices/blob/master/readme-es.md) - Yoni Goldberg (español). Una guía larga de buenas prácticas: nombres de tres partes, preparar-actuar-comprobar, datos realistas, cobertura y mutantes. Lee las secciones 0 («La Regla de Oro») y 1 («La Anatomía de un Test»). Repaso de las teorías 04 y 05.
3. [Bugs and Errors](https://eloquentjavascript.net/08_error.html) - *Eloquent JavaScript*, 4.ª edición, de Marijn Haverbeke (inglés). El capítulo de errores, con un apartado sobre tests automáticos. Lectura opcional.
