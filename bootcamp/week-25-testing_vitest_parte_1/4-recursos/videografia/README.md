# 🎬 Videografía - Semana 25

1. [Testing con Vitest](https://www.youtube.com/watch?v=OpaDMD_JgSc) - DesarrolloWeb.com (español). Tests con Vitest a partir de katas, ejercicios pequeños que se resuelven test a test. Repaso de los labs 01 y 03.
2. [Aprende a usar VITEST en BACKEND: Testing con Node.js](https://www.youtube.com/watch?v=RX-qVRnuD5E) - Developero (español). Instalar y configurar Vitest en un proyecto de Node. Instala con npm: en el bootcamp, usa siempre `pnpm add -D --save-exact`.
3. [JEST JS tutorial en español para principiantes](https://www.youtube.com/watch?v=tgWBQZNCOT0) - Developero (español). Los primeros tests con Jest. `describe`, `it`, `expect` y los matchers funcionan igual en Vitest. Repaso de la teoría 03.
4. [Curso de Test Driven Development desde cero con JavaScript, React y Vitest](https://www.youtube.com/watch?v=_t9l2TwGioc) - midulive (español). Escribir el test antes que el código. La primera parte, sin React, es un adelanto de la semana 26. Opcional.
5. [VanillaJS Frontend Testing: Unit Testing JavaScript with Vitest](https://www.youtube.com/watch?v=nu9ohmfl8uQ) - Systementor Learning (inglés). Tests unitarios con Vitest para JavaScript sin frameworks, separando la lógica de la página como en los proyectos del bootcamp.
