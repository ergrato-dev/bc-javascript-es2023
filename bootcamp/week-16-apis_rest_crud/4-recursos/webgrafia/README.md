# 🌐 Webgrafía - Semana 16

## Documentación

1. [MDN - Métodos de petición HTTP](https://developer.mozilla.org/es/docs/Web/HTTP/Methods) y [Códigos de estado](https://developer.mozilla.org/es/docs/Web/HTTP/Status): cada método y cada estado de la teoría 01, con su página propia.
2. [MDN - Idempotent](https://developer.mozilla.org/en-US/docs/Glossary/Idempotent): la definición, con el ejemplo de `DELETE` (inglés).
3. [MDN - Autenticación HTTP](https://developer.mozilla.org/es/docs/Web/HTTP/Authentication): `401`, `403`, `WWW-Authenticate` y los esquemas `Basic` y `Bearer`.
4. [MDN - Link](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Link): la cabecera de paginación del lab 02 (inglés).
5. [MDN - aria-busy](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-busy): el atributo para avisar de que una zona de la página se está cargando (inglés).
6. [RFC 9110 - HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) y [RFC 9457 - Problem Details](https://www.rfc-editor.org/rfc/rfc9457): la especificación de los métodos y estados, y el formato estándar de los errores (inglés).

## Guías y artículos

7. [GitHub Docs - Using pagination in the REST API](https://docs.github.com/en/rest/using-the-rest-api/using-pagination-in-the-rest-api): cómo pagina una API real con la cabecera `Link` (inglés).
8. [jwt.io - Introduction to JSON Web Tokens](https://jwt.io/introduction): las tres partes de un JWT; su página principal decodifica cualquier token (inglés).
9. [OWASP - HTML5 Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html), sección *Local Storage*: por qué no guardar tokens en `localStorage` (inglés).
10. [OWASP - Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html): mensajes de error genéricos al iniciar sesión, contraseñas y sesiones (inglés).
