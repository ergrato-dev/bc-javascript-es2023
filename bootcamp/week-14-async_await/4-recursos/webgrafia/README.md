# 🌐 Webgrafía - Semana 14

## Documentación

1. [MDN - async function](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Statements/async_function): declaración, valor de retorno y ejemplos.
2. [MDN - await](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Operators/await): qué espera, qué hace con valores que no son promesas y *top-level await*.
3. [MDN - for await...of](https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Statements/for-await...of): recorrer iterables asíncronos y generadores asíncronos.
4. [MDN - Array.fromAsync()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/fromAsync): reunir un iterable asíncrono en un array (inglés).
5. [JavaScript.info - Async/await](https://es.javascript.info/async-await) y [Iteradores y generadores asíncronos](https://es.javascript.info/async-iterators-generators): explicación con ejercicios.

## Artículos

6. [V8 - Faster async functions and promises](https://v8.dev/blog/fast-async): cómo ejecuta el motor `await` y por qué hoy no es más lento que `.then()` (inglés).
7. [Node.js - Módulos ES](https://nodejs.org/api/esm.html): cuándo trata Node un archivo como módulo, que es lo que permite el *top-level await* (inglés).
