# Prácticas — Semana 14

Cuatro labs guiados. Cada lab trae en `starter/` el código comentado: lo descomentas paso a paso, lo ejecutas con Node y comparas con la salida esperada del README. Antes de ejecutar, intenta predecir el orden de las líneas y, en el lab 03, cuánto tardará cada paso. No se entregan; preparan el [proyecto de la semana](../3-proyecto/README.md).

| Lab | Tema | Duración |
|---|---|---|
| [Lab 01](lab-01-async-basico/README.md) | Funciones `async`, `await`, de `.then()` a `await` y orden de ejecución | 50 min |
| [Lab 02](lab-02-error-handling/README.md) | `try`/`catch`/`finally`, errores propios, `cause`, `return await` y reintentos | 55 min |
| [Lab 03](lab-03-parallel-vs-sequential/README.md) | En orden o a la vez, `Promise.all`, `forEach` con `async` y concurrencia limitada | 55 min |
| [Lab 04](lab-04-async-iteration/README.md) | `for await...of`, generadores asíncronos, paginación y `Array.fromAsync` | 50 min |

**Total:** 3 h 30 min.

## Antes de empezar

Comprueba que tienes Node instalado (versión en [docs/stack-versions.md](../../../docs/stack-versions.md)):

```bash
node --version
# v24.19.0 (o superior)
```
