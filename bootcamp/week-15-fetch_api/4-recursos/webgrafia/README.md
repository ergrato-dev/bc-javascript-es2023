# 🌐 Webgrafía - Semana 15

## Documentación

1. [MDN - Usando Fetch](https://developer.mozilla.org/es/docs/Web/API/Fetch_API/Using_Fetch): la guía de referencia, con cuerpos, cabeceras, `Request` y comprobación de errores.
2. [MDN - Métodos de petición HTTP](https://developer.mozilla.org/es/docs/Web/HTTP/Methods) y [Códigos de estado](https://developer.mozilla.org/es/docs/Web/HTTP/Status): qué significa cada método y cada estado.
3. [MDN - AbortSignal.timeout()](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal/timeout_static): la señal con tiempo máximo que usan el lab 03 y el proyecto (inglés).
4. [Node.js - Objetos globales](https://nodejs.org/api/globals.html): `fetch`, `Request`, `Response`, `Headers` y `AbortSignal` vienen incluidos en Node sin instalar nada (inglés).
5. [JavaScript.info - Fetch](https://es.javascript.info/fetch), [Abort](https://es.javascript.info/fetch-abort) y [Fetch API](https://es.javascript.info/fetch-api): explicación con ejercicios.

## Artículos

6. [web.dev - Introduction to fetch()](https://web.dev/articles/introduction-to-fetch): de `XMLHttpRequest` a `fetch`, con respuestas, cabeceras y modos (inglés).
7. [Dmitri Pavlutin - How to Use Fetch with async/await](https://dmitripavlutin.com/javascript-fetch-async-await/): errores HTTP, cancelación y peticiones en paralelo, el mismo recorrido que los labs (inglés).
