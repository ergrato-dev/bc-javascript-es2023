# 📖 Ebooks gratuitos - Semana 15

## Fetch y HTTP

1. **Eloquent JavaScript - Capítulo 18: HTTP and Forms** - Marijn Haverbeke
   - Enlace: [eloquentjavascript.net](https://eloquentjavascript.net/18_http.html)
   - Secciones: *The protocol*, *Fetch* y *HTTP sandboxing*
   - Nivel: principiante · Idioma: inglés

2. **JavaScript.info - Parte 3: Network requests** - Ilya Kantor
   - Enlace: [javascript.info](https://javascript.info/network)
   - Capítulos sobre `fetch`, `FormData`, progreso de descarga, cancelación, CORS y la API completa de `fetch`; varios están traducidos en [es.javascript.info](https://es.javascript.info/fetch)
   - Nivel: principiante a intermedio · Idioma: inglés y español
