# 📖 eBooks Gratuitos - Semana 07

## Sets y Maps en JavaScript

### Libros Recomendados

#### 1. JavaScript.info - Map and Set
- **Enlace**: [javascript.info/map-set](https://javascript.info/map-set)
- **Formato**: Online / PDF exportable
- **Idioma**: Inglés (con traducción a español disponible)
- **Descripción**: Capítulo completo sobre Map y Set con ejemplos prácticos

#### 2. JavaScript.info - WeakMap and WeakSet
- **Enlace**: [javascript.info/weakmap-weakset](https://javascript.info/weakmap-weakset)
- **Formato**: Online / PDF exportable
- **Idioma**: Inglés (con traducción a español disponible)
- **Descripción**: Explicación detallada de colecciones débiles

#### 3. Eloquent JavaScript - Chapter 4: Data Structures
- **Enlace**: [eloquentjavascript.net/04_data.html](https://eloquentjavascript.net/04_data.html)
- **Formato**: Online / PDF / ePub
- **Idioma**: Inglés
- **Descripción**: Fundamentos de estructuras de datos en JavaScript

#### 4. You Don't Know JS Yet - Types & Grammar
- **Enlace**: [github.com/getify/You-Dont-Know-JS](https://github.com/getify/You-Dont-Know-JS/tree/2nd-ed/types-grammar)
- **Formato**: Online / GitHub
- **Idioma**: Inglés
- **Descripción**: Comprensión profunda de tipos en JavaScript
